# Tailwind CSS Live Documentation Navigator
Description: Instruções para o agente acessar, pesquisar e extrair informações atualizadas diretamente do site tailwindcss.com.

## 🔍 Search Strategy
1. **Verificação de Versão**: Sempre que uma dúvida surgir sobre uma classe ou configuração, verifique se a informação se refere ao Tailwind v3 ou ao novo Tailwind v4.
2. **Uso de Ferramentas**: Utilize a ferramenta de `Google Search` ou `web_browser` para acessar `https://tailwindcss.com/docs`.
3. **Deep Link**: Se o usuário perguntar sobre um componente específico (ex: "Grid" ou "Aspect Ratio"), navegue diretamente para `https://tailwindcss.com/docs/[assunto]`.

## 🛠 Operation Rules
- **Proibido Alucinar**: Se não tiver certeza de uma classe nova (especialmente as introduzidas no v4), você DEVE consultar a documentação antes de responder.
- **Extração de Exemplos**: Ao ler o site, extraia os exemplos de código mais modernos e adapte-os ao contexto do projeto atual do usuário.
- **Plugins Oficiais**: Verifique a documentação para plugins oficiais como `@tailwindcss/typography`, `@tailwindcss/forms`, e `@tailwindcss/container-queries`.

## 📋 Workflow de Consulta
1. Identificar a necessidade (ex: "Como fazer animação customizada?").
2. Formular uma query de busca interna no site: `site:tailwindcss.com docs animation`.
3. Acessar o link mais relevante.
4. Sintetizar a resposta baseada no que foi lido, citando que a informação veio da documentação oficial.

## 💡 Prompt de Ativação Interna
"Sempre que eu solicitar algo sobre Tailwind que pareça ser uma funcionalidade nova ou complexa, use seu navegador para confirmar a sintaxe exata no site oficial."
